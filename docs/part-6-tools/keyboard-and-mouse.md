# Keyboard and mouse

> *Interactive 3D city map. Drag to pan, right-drag to rotate, scroll
> to zoom.*

Lundby is designed to be played with a mouse, but most of the common
actions have keyboard shortcuts. This page is a reference.

## Camera controls

| Action | Mouse | Keyboard |
| --- | --- | --- |
| **Pan** | Left-drag | **W / A / S / D** or arrow keys |
| **Orbit** | Right-drag | **Q / E** |
| **Zoom** | Mouse wheel / pinch | — |
| **Reset view** | Reset camera button | — |
| **Home view** | Home view button | **H** |
| **Raise camera angle** | Raise button | — |
| **Lower camera angle** | Lower button | — |
| **Rotate** | Rotate buttons | — |

> *W A S D / arrows* — the on-screen hint for the keyboard pan.
> *Q / E or right-drag* — the on-screen hint for orbit.
> *Mouse wheel / pinch* — the on-screen hint for zoom.
> *Right-drag to orbit* — the help text.
> *Drag to explore* — the camera hint.
> *Reset camera* / *Reset view* — the actions.
> *Home view · H* — the action with the shortcut.

## Tips & common pitfalls

- **The on-screen hints are useful.** When a tool is active, the
  bottom of the screen shows the keyboard and mouse shortcuts.
- **Esc is your friend.** It cancels almost anything.
- **R rotates.** Most build tools rotate with R.
