# The transport network report

> *Transport & routes*

The transport network report is a live view of every line, every
vehicle, and every stop in your city's transit network. It's where you
go to debug a stuck train, balance a headway, or check on a
delivery.

## Where to find it

- **City → Transport & routes → Transport network report**

> *Transport network report* — the report.
> *Transport overview* — the panel.
> *Transport network* — the section.

## Tips & common pitfalls

- **The transport network report is the place to debug.** A line that
  says it's running but no vehicles are dispatched? Check the depot.
- **Headway is the lever.** A 5-minute headway costs more than a
  15-minute one.
- **Fares pay for service.** Set them too high and ridership falls.
- **A broken line is worse than no line.** Pause broken lines
  rather than let them fail silently.
